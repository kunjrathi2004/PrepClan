# MongoDB URI Verification & Fix

## Status Check ✅
- MongoDB Atlas IP Whitelist: ✅ Configured (0.0.0.0/0 Active)
- Issue: MongoDB URI in Railway is likely incorrect

## Problem
Since IP whitelist is correct, the issue is with the connection string format or credentials.

## Get Correct MongoDB Connection String

### Step 1: Get Fresh Connection String from MongoDB Atlas

1. Go to https://cloud.mongodb.com
2. Click on your cluster (Cluster0)
3. Click **"Connect"** button
4. Select **"Connect your application"**
5. Driver: **Node.js**
6. Version: **5.5 or later**
7. Copy the connection string shown

It will look like:
```
mongodb+srv://<username>:<password>@cluster0.62700bc.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0
```

### Step 2: Modify the Connection String

Replace the placeholders:

**Original:**
```
mongodb+srv://<username>:<password>@cluster0.62700bc.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0
```

**Modified (add database name):**
```
mongodb+srv://USERNAME:PASSWORD@cluster0.62700bc.mongodb.net/prepclan?retryWrites=true&w=majority&appName=Cluster0
```

### Step 3: URL-Encode Password

If your password has special characters, encode them:

**Common Special Characters:**
```
@ → %40
! → %21
# → %23
$ → %24
% → %25
^ → %5E
& → %26
* → %2A
( → %28
) → %29
+ → %2B
= → %3D
/ → %2F
: → %3A
```

**Example:**
- Username: `prepclan`
- Password: `PrepClan@2026!`
- Encoded Password: `PrepClan%402026%21`

**Final URI:**
```
mongodb+srv://prepclan:PrepClan%402026%21@cluster0.62700bc.mongodb.net/prepclan?retryWrites=true&w=majority&appName=Cluster0
```

## Update Railway Environment Variable

### Method 1: Via Railway Dashboard

1. Go to Railway dashboard: https://railway.app
2. Select your PrepClan service
3. Click **"Variables"** tab
4. Find `MONGODB_URI`
5. Click to edit
6. Paste the corrected connection string
7. Click "Update" or press Enter
8. Railway will automatically redeploy

### Method 2: Delete and Re-add

1. In Railway Variables tab
2. Click the "X" to delete `MONGODB_URI`
3. Click "New Variable"
4. Variable name: `MONGODB_URI`
5. Value: Your corrected connection string
6. Click "Add"

## Common MongoDB URI Mistakes

### ❌ Mistake 1: Missing Database Name
```
mongodb+srv://user:pass@cluster0.62700bc.mongodb.net/?retryWrites=true
```

### ✅ Correct:
```
mongodb+srv://user:pass@cluster0.62700bc.mongodb.net/prepclan?retryWrites=true
```

### ❌ Mistake 2: Special Characters Not Encoded
```
mongodb+srv://user:Pass@123!@cluster0.62700bc.mongodb.net/prepclan
```

### ✅ Correct:
```
mongodb+srv://user:Pass%40123%21@cluster0.62700bc.mongodb.net/prepclan
```

### ❌ Mistake 3: Wrong Cluster URL
```
mongodb+srv://user:pass@cluster1.mongodb.net/prepclan
```

### ✅ Correct (check your actual cluster URL):
```
mongodb+srv://user:pass@cluster0.62700bc.mongodb.net/prepclan
```

### ❌ Mistake 4: Using mongodb:// instead of mongodb+srv://
```
mongodb://user:pass@cluster0.62700bc.mongodb.net/prepclan
```

### ✅ Correct:
```
mongodb+srv://user:pass@cluster0.62700bc.mongodb.net/prepclan
```

## Debugging Steps

### Check Railway Logs for Exact Error

1. Railway Dashboard → Your Service → Deployments
2. Click latest deployment
3. View logs
4. Look for MongoDB error messages

**Common errors:**

**Error 1: Authentication failed**
```
MongoServerError: Authentication failed
```
**Fix:** Wrong username or password

**Error 2: Connection timeout**
```
MongooseServerSelectionError: connect ETIMEDOUT
```
**Fix:** Check cluster URL is correct

**Error 3: Bad auth**
```
MongoServerError: bad auth : Authentication failed
```
**Fix:** Password not URL-encoded or wrong credentials
