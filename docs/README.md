# PrepClan - CAT 2026 Preparation Platform

A comprehensive website for CAT 2026 and other ADMAT exam preparation including XAT, SNAP, NMAT, etc.

## Project Structure

```
PrepClan/
├── index.html                 # Homepage
├── about.html                 # About Us page
├── contact.html               # Contact Us page
├── assets/
│   ├── css/
│   │   └── style.css         # Main stylesheet
│   ├── js/
│   │   └── main.js           # JavaScript for interactivity
│   └── images/               # Images folder (add your images here)
├── pages/
│   ├── mentoring/
│   │   └── mentoring.html    # 1-1 Mentoring page
│   ├── content/
│   │   ├── content.html      # Daily Content hub
│   │   ├── rc.html           # RC practice page
│   │   ├── dilr.html         # DILR practice page
│   │   ├── qa.html           # QA practice page
│   │   └── va.html           # VA practice page
│   └── mocks/
│       └── mocks.html        # Mock Tests page (Phase 2)
└── README.md                 # This file
```

## Features

### 1. 1-1 Mentoring
- Personalized guidance for CAT 2026, XAT, SNAP, NMAT
- Three pricing tiers: Basic, Standard, Premium
- Custom study plans and progress tracking

### 2. Daily Content
- **RC (Reading Comprehension)**: 5 sets daily
- **DILR (Data Interpretation & Logical Reasoning)**: 5 sets daily
- **QA (Quantitative Aptitude)**: 40 questions daily (topic-wise)
- **VA (Verbal Ability)**: 40 questions daily (para summary, para completion, odd one out, etc.)

### 3. Timed Mock Tests (Phase 2 - Coming Soon)
- Previous years' papers
- Real exam simulation with timer
- Detailed performance analysis

## Design Features

## How to Use

1. Open `index.html` in a web browser to view the homepage
2. Navigate through different sections using the navigation bar
3. All pages are interconnected with proper navigation

## Deployment

This website is ready to be deployed on Railway or any other hosting platform:
1. Upload all files maintaining the folder structure
2. Set `index.html` as the entry point
3. Configure your domain settings
